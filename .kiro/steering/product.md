# Product Overview

Quiz Generator - An AI-powered application that generates custom multiple-choice quizzes on any topic using Google's Gemini LLM.

## Core Features

- Generate 3-15 multiple choice questions on user-specified topics
- Each question has 4 options with one correct answer
- Real-time quiz generation powered by Gemini 2.0 Flash
- Interactive quiz interface with immediate feedback
- User authentication system with SQLite backend

## User Flow

1. User enters a topic and selects number of questions (3-15)
2. Backend calls Gemini LLM to generate structured quiz questions
3. Frontend displays interactive quiz with option selection
4. User completes quiz and can generate new quizzes
